    Como usar

    1. Baixe o .zip da skill que você quer.
    2. Descompacte dentro da pasta de skills da sua ferramenta, por exemplo .claude/skills/ no Claude Code ou .github/skills/ no GitHub Copilot.
    3. Peça a tarefa normalmente. O agente decide quando usar a skill pela descrição dela.
